## 重建

本目录的两张独立素材按像素提取自 PR 的无损三视图切片。提取坐标和文件哈希见[生成记录](生成记录/)。

复制一份含 22 张独立素材的 Grok 娘原制作工程。在副本中替换 `制作清单.json`，再把本目录的 `01_三视图/`、`生成记录/` 和 `提示词/` 中的新增文件放入副本的对应目录。工程使用 `00_生成记录/` 和 `00_提示词/` 时，沿用这两个目录名。

从仓库根目录依次运行拼板、校验和导出脚本，把下列“工程副本”换成副本路径。

```text
python scripts/compose_landscape.py "工程副本"
python scripts/verify_board.py "工程副本"
python scripts/make_viewable.py "工程副本"
python scripts/make_native_slices.py "工程副本"
```

应通过 22 张素材的逐字节校验。生成的三视图原像素切片应与本目录的 PNG 像素一致。
