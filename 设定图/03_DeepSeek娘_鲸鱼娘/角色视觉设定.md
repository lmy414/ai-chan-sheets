## 二、身份与造型锚点

- 少女体型。**深蓝色长发**，发丝厚重、发梢渐变为浅蓝，发丝间有浅蓝挑染高光分束，发长过腰、发尾蓬松外翻。
- **头顶一根细长呆毛向上卷成闭合圆环**。本角色的强识别特征。
- **两侧各一枚鲸鱼鳍形状的鳍耳**：鳍面深蓝带浅蓝渐变高光，边缘是白色羽状鳍条，鳍根配蓝色小蝴蝶结。这是身份标志，**不可当成猫耳/兔耳**。
- 蓝色大眼睛，柔和二次元脸型，淡粉腮红。
- 服装为**深藏青女仆装**：白色泡泡袖（袖口白色蕾丝 + 金属扣）、深藏青紧身袖套、深藏青马甲前襟带金色纽扣与金线滚边、白色立领与胸前白色褶饰、**黑色小蝴蝶结颈饰中央嵌一颗蓝色宝石**。
- **白色围裙**：整圈荷叶边包边，胸挡 + 裙幅，**右下角绣一只蓝色小鲸鱼**（带喷水花）。
- **多层长裙**：深藏青外层（浅金色缠枝花卉纹 + 两处深色小蝴蝶结）→ 蓝白细竖条纹中层 → 白色荷叶边衬裙。
- **身后伸出一条鲸鱼尾形尾鳍**（水平尾叶）。
- 白色连裤袜 + 深藏青玛丽珍鞋（圆头、低粗跟、脚背横带配金色小方扣）。
- 白色多层褶皱女仆头饰，两侧垂白色蕾丝缎带。

整体配色：**深藏青 / 白 / 蓝**，点缀浅金。无暖色、无红紫。

## 三、表情范围（8 张）

自然微笑、平静、惊讶、害羞、鼓腮、闭眼轻笑、认真、委屈各一张，统一胸像机位。
构图固定包含：呆毛、女仆头饰、两侧鳍耳、蓝色小蝴蝶结、黑色蝴蝶结颈饰（含蓝宝石）、泡泡袖肩部。
`平静` 作为脸型与机位基准；只通过眉、眼、嘴与必要脸红表达情绪。

## 六、横版拼接

- `scripts/compose_landscape.py`：分区横向并排，每个分区占一行，行内素材从左到右。
- 所有素材**原生像素 1:1 粘贴**，不缩放、不裁切；透明像素按标准 alpha 合成到白底。
- 成品：`05_横版设定板/DeepSeek娘_鲸鱼娘_横版完整设定图_原像素.png` 与 `_浏览预览.jpg`。
- `06_便于查看/`：整板总览 + 4 张分区查看图（长边 ≤ 4000px）。原像素母版超过 1 亿像素，
  Windows 照片查看器会解码失败并**误报「文件不存在」**，看图请用 `06_便于查看/` 里的文件。

## 七、生成过程备注

- 22 张中 21 张首次成功，`D04_道具_颈饰` 首次因上游间歇性错误失败，退避重跑后补齐，无一张降质跳过。
- 实测并发上限：同时 3 至 4 个请求会触发上游缓冲超限（503/507），**单进程串行最稳**。
- 素材为 RGBA，alpha 是**柔性遮罩**（几乎没有完全不透明的像素）。因此：
  - 审图时必须先合成白底再转 RGB；若直接对 RGBA 调 `convert('RGB')`，
    透明区会显示成黑色并出现噪点。**这是预览代码的问题，素材本身正常**（本工程已亲历一次并排查确认）。
